# 产品档案

每个产品建立 `products/<product-id>/README.md`，使用 [统一模板](../templates/product-profile.md)。标识使用稳定的英文小写名称，产品改名时保留标识并记录曾用名。同一产品在不同榜单中复用档案，历史排名保留在对应 research 目录。

研究基本信息、发布节点、功能、公开数据、营销、与其他产品的关系和招聘。未知标为“待核实”；未找到公开资料时记录检索日期，不把缺失写成 0。每条主要事实引用档案中的来源编号，变化较快的信息注明观察日期。

公开文章放在该产品的 articles/ 目录，并从档案链接；跨产品综述放在研究批次的 articles/。草稿和对话留在本地 private/。
