# AI 产品研究

跟踪全球主流 AI 产品的演进脉络、商业化定价与真实用户数据。收录 110+ 款产品的结构化商业档案、主流行业榜单快照与深度拆解文章。

## 为什么是现在

AI 产品刚出来时，大家主要看模型跑分、Demo 演示和免费试用。行业榜单也多是统计网页访问量或 App 下载量。

但访问量大不代表有人愿意持续付费。很多高访问量的产品算力成本居高不下、用户留存很低；而一些没有公关声量、直接嵌入具体工作流的桌面工具、代码助手和 Agent，反而有很高的付费率和客单价。

评估现在的 AI 产品不能只看访问量，更需要看真实的留存、定价策略以及用户到底在为什么买单。
